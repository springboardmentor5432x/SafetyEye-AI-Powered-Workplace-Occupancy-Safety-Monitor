# 🦺 Final Project Report
## Safety Eye Pro – AI-Based PPE Monitoring System

---

## 1. Introduction
Safety Eye Pro is an AI-powered system designed to monitor PPE compliance in workplaces using real-time video analysis.

---

## 2. Objectives
- Detect PPE usage
- Identify violations
- Alert authorities
- Record unsafe events
- Generate reports

---

## 3. System Architecture
Camera → YOLO Model → Detection Engine → UI Dashboard → Logs & Reports

---

## 4. Technologies Used
- Python
- YOLOv8
- OpenCV
- Streamlit

---

## 5. Key Features
- Real-time PPE detection
- Smart alerts
- Video recording
- Screenshot capture
- Safety score analytics
- Interactive dashboard

---

## 6. Results
- High detection accuracy
- Reduced false alerts
- Real-time performance achieved

---

## 7. Applications
- Construction sites
- Factories
- Industrial zones

---

## 8. Advantages
- Automated monitoring
- Improved safety compliance
- Reduced human effort

---

## 9. Limitations
- Depends on camera quality
- Performance affected in low light

---

## 10. Future Scope
- Mobile notifications
- Cloud deployment
- Multi-camera integration

---

## 11. Conclusion
The project successfully demonstrates the use of AI in improving workplace safety through intelligent monitoring systems.
