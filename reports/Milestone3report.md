# 🧾 Milestone 3 Report

---

## 1. Objective
To implement real-time PPE detection using webcam input.

---

## 2. System Architecture
Camera → Frame Capture → YOLO Model → Detection → Output Display

---

## 3. Implementation
- OpenCV used for webcam access
- Frames passed to YOLO model
- Bounding boxes drawn on detected objects

---

## 4. Features Implemented
- Real-time detection
- Label display
- Multiple object tracking

---

## 5. Performance
- Smooth detection at ~20–30 FPS
- Works on live camera feed

---

## 6. Challenges
- Lag in processing
- Lighting issues

---

## 7. Solutions
- Reduced frame size
- Optimized processing loop

---

## 8. Outcome
Fully functional real-time PPE detection system.

---

## 9. Conclusion
Milestone 3 successfully integrated AI model with live video feed.
